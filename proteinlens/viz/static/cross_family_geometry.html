DB-silent features that geometry annotates

Each row in the main table is a feature. A feature is DB-silent when all four database methods — InterPro protein, InterPro residue, CATH protein, CATH residue — return q ≥ 0.05. It becomes DB-silent geometry-annotatable when the geometric method (method 7) has q < 0.05 on top of that. A tighter subset is purely geometric: only geometry is significant among the seven methods (position and MEME motif are also not significant).
