Geometry is more granular than biology

Features are grouped by the residue-level DB annotation they share (InterPro-residue or CATH-residue), not by the broader protein-level family. We then ask which methods actually distinguish the members of each group. Geometry often does — different features pick up different sub-structures (curvature vs compactness vs contacts) within the same residue-level annotation. This page also flags groups where MEME or sequence-position distinguishes the features while geometry doesn't.

Input filter: geometry q < 0.05, sparse (protein coverage ≤ the threshold set at build time, default 20%), AND (for each DB source) the matching residue-level method is also q < 0.05 (InterPro-res for the InterPro groups, CATH-res for the CATH groups). Other methods may also be significant — the axes below separate them. Geometry-distinguishable = members show ≥2 distinct top structural categories (or top geometric features). MEME-distinguishable = among features with m6 q < 0.05, ≥2 distinct top MEME consensus strings. Position-distinguishable = among features with m5 q < 0.05, ≥2 distinct top predicates.
